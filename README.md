# driver-drowsiness-detection-yolov8
# Driver Drowsiness Detection using YOLOv8

Computer vision system developed to detect driver drowsiness using YOLOv8 and NVIDIA Jetson Xavier NX.

## Technologies

- Python
- YOLOv8
- OpenCV
- Roboflow
- Jetson Xavier NX
- Flask

## Results

mAP@0.5: 0.676
Recall: 0.67

## Features

- Eye closure detection
- Yawning detection
- PERCLOS monitoring
- Event logging
- Web dashboard
